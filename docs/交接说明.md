# Terrain Recast 交接说明（接手前必读）

> Fabric 侧，MC 26.3，目录 `f:\新·模组开发\Terrain Recast`。下方为当前进度、待办与全部踩坑记录。

## 一、项目定位
板块制地形模组，用自定义 DensityFunction 替换原版 overworld 地形管线，突出「板块碰撞→大地貌→气候→侵蚀→岩性」的生成链。全部结论遵守：**连续性优先**，禁止 Voronoi 直边/垂直断崖（历史上踩过 138 格跳变的坑）。

## 二、当前完成管线
- L0 板块：`WorleyDistance` 软 Voronoi，`RealCellLookup` 三近板块距离加权混合连续场。
- L1 大地貌：板块边界造山/海沟 + 软下限 + 大陆度。
- L2 气候五维：温度/湿度/怪异度/侵蚀连续化，`continents` 绑定真实地形高度(海陆群系自洽)。
- L3 河谷下切 `carveRiver`。
- L4 侵蚀塑形（`realCellLookup.terrainHeight` 内 EROSION 包络，老年地貌磨圆山脊+填谷）。
- L5 岩性 Java 侧：`populateL5` 按板块细分岩性 + `StrataDensityFunction` 绑定真实地表高度（分层）。
- 已注册 DensityFunction 类型 8 个，全部在 ModInitializer 阶段（冻结前）注册。
- **下界重塑（火山熔岩世界）**：`NetherVolcanoDensityFunction` 覆写 `nether/base_3d_noise.json`，`slideNetherLike` 唯一地形源。基床熔岩海托破火山口锥群 + 熔岩裂谷整列垂直切割（高位归零防凿穿天花板），场地一致、max 取并集连续。已构建并用户认可。
- **末地重塑（碎裂大陆）**：`EndShatteredContinentFunction` 覆写 `end/base_3d_noise.json`，**保留原版主岛**（不归零 end/islands.json），`add` 叠加到原版主岛上使其更壮观——原点厚山地隆起板（穹顶高原+ridged 山脊+海岸域变形）+ 外侧格网碎裂群岛簇。max 取并集连续，虚空基线 -0.6。已构建，待用户进末地验证观感。

## 四、踩坑记录（务必看完）
1. **DensityFunction 接口在 26.3 完全重构**：旧 `compute/fillArray` 废弃，必须适配新版 `compileSampler + DensitySampler` 体系。
2. **自定义 DensityFunction 类型必须注册 `BuiltInRegistries.DENSITY_FUNCTION_TYPE`，且在 ModInitializer 阶段（冻结前）**。MaterialRule/Condition 类型同理。
3. **`dimension_type` 26.3 配置必须完整 schema**：含 `monster_spawn_block_light_limit` 等根级必填字段；用简化版会导致创建世界卡死。
4. **`noise_settings` 覆盖采用最小改动原则**：只改需要串联的字段，其余保留原版默认，否则 schema 不兼容卡死。
5. **误创建与原版重名的 density_function 条目**会导致循环依赖/覆盖冲突。用新条目（如 `trc_cell_offset`）在内部叠加原版值（tectonic 模式）。
6. **不要直接替换原版 continents/erosion 连续噪声管线**，会造成区块断崖式跳变。要保留原版噪声链并叠加低频修正项（小系数叠加：landformHeight 0.003、continentalness 0.15、plateBoundary -0.05）。
7. **Cell 字段到地形的平滑必须由原版 `minecraft:interpolated` 统一处理**；禁止在 CellFieldSampler 内部自行插值（双重插值导致信号抹平/区块跳变）。
8. **板块身份是离散量，禁止作为高度顶点依赖**：Voronoi 顶点「第三近板块」换人处会产生上百方块垂直断崖。所有高度量都要用连续场（软 Voronoi 距离加权），或用原版 interpolated 平滑。
9. **multi-Variable 同时改会无法定位根因**：地形适配要分阶段独立验证（先纯原版，再叠加 Cell offset，最后单独处理高度）。
10. **出生地凹陷**不能只靠单一强制大陆规则解决，需统一板块类型判定来源、避免多逻辑分支不一致。
11. **类加载/中文路径**：部分子代理读不了含 `·`/中文的源码路径（os error 3），需主代理自己 Read。
12. **构建命令禁止自动加 clean**（除非用户明确说清理）：`$env:JAVA_HOME="C:\Program Files\Java\jdk-25"; .\gradlew build --no-configuration-cache`（Loom 1.19-SNAPSHOT 要求 JVM 25，需显式 JAVA_HOME）。
13. **禁止 ThreadLocal 存全局状态**（UTF 线程串扰）；生命周期绑定资源必须 AutoCloseable 并显式 close()，防内存泄漏。
14. 出生点附近地形曾强制大陆膨胀（`SPAWN_LAND_*`），保证出生区块是陆地。
